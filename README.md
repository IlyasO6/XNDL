# XNDL – Neural Networks and Deep Learning

Graded labs of *Neural Networks and Deep Learning* (XNDL), Bachelor's Degree in Artificial Intelligence, FIB-UPC (2025-26). Done in pairs (Laia Beyloc and Ilyas Ouacham).

| Folder | Content |
|---|---|
| [`practica2/`](practica2/) | **Doodle classification from scratch.** ResNet9 with squeeze-and-excitation, trained in under 5 minutes on a GPU without pretrained weights. 87.37% validation accuracy, grade 9.93/10. See its README for the model and the experiments. |
| [`practica1/`](practica1/) | Partial lab: classic machine learning. The main exercise (`ex4.ipynb`) predicts whether a patient will become disoriented after a dose of a new drug, comparing models such as logistic regression and SVM with grid and random search for hyperparameter tuning. |

The datasets are course material and are not included in the repository.
